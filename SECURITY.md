# Security

## Report a vulnerability

Email **support@getshahi.dev** with the affected version or commit, reproduction
steps, and expected impact. Do not post credentials, pairing codes, or private
transcripts in a public issue. Use synthetic sessions in reproductions.

Please report an unpatched vulnerability privately before publishing exploit
details. There is no guaranteed response time or bug-bounty program.

## Supported code

Security fixes are maintained on `master`. Older snapshots may lack fixes;
there is no long-term-support release policy. A GitHub fix does not update an
installed sidecar or mobile build automatically.

For historical findings and their remediation, see the
[documentation index](docs/README.md#historical-reviews). Review scopes and
limitations remain part of those reports; passing tests are not a security
certification.
