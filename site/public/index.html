Connection security

How your connection is protected.

Your phone and computer connect outbound to a relay, so your local Shahi port stays private. Application data is encrypted between your devices before it reaches the relay.

What happens when I scan the code?
  1. The code introduces your phone to your computer with a temporary secret. It expires after ten minutes and can be claimed once.
  2. Both devices establish an encrypted channel. The secret is not exposed to the relay in plaintext.
  3. Your computer gives the paired device its own credentials. Future connections prove possession of that secret before access is granted.
  4. You can revoke a device in Settings. Its connection closes and further authenticated requests are refused.

Treat an unused QR code or pairing link as a credential: pairing grants access to your terminal.

What can the relay see—and what must I trust?

The relay forwards encrypted application content. It and Cloudflare can observe IP addresses, identifiers, and traffic sizes and timing. Operational metadata is collected for reliability and abuse diagnosis.

Your phone and computer can read the data they decrypt. The browser app also trusts the code published on getshahi.dev. Optional push providers receive notification content through a separate delivery path. Encryption does not protect a compromised endpoint or guarantee availability.

Shahi uses X25519, HKDF-SHA-256, and ChaCha20-Poly1305. Published project reviews are internal assessments, not an independent security certification.

Setup

Install. Scan. Connect.

Run these commands on your Mac or Linux computer with herdr installed. Then scan the pairing code in Shahi.

Setup documentation ↗
On your computer
herdr plugin install iYassr/shahi
herdr plugin action invoke shahi.pair

Each code can be used once and expires after 10 minutes.
