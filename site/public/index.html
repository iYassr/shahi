Setup

Install. Scan. Connect.

Two commands in herdr on your Mac or Linux computer, then one scan on your phone: about a minute once herdr is running. The Shahi tunnel is included and connects automatically after pairing.

On your phone, open getshahi.dev/pwa and tap Scan QR code, or scan it with the iOS app. Your camera app can’t pass this code to the browser, so scan it from inside Shahi.

New to herdr? Shahi shows the agents you run inside it. Install herdr first, then start your agents there.

Step-by-step setup guide ↗
On your computer, in herdr
herdr plugin install iYassr/shahi
herdr plugin action invoke shahi.pair

Needs herdr 0.9.0 or newer, git, and bun 1.3.13 or newer (if bun is missing, the install adds it), on macOS or Linux. Automatic background setup on Linux uses systemd. Each code can be used once and expires after 10 minutes.

What Shahi does

01

Encrypted end to end, and live

Your phone and computer encrypt every message they send each other. Shahi’s relay passes them along without being able to read them, so there is no Shahi account, no VPN and no open port. Conversations update as the agent writes.

02

Like WhatsApp, for your agents

Messages, reasoning, supported tool results and file changes become a conversation made for your phone. Permission prompts Shahi recognises become buttons. Reply in a few taps and watch the agent carry on.

03

Built on herdr

herdr is a lightweight home for your agents, with spaces, panes and live status for every one. Shahi mirrors all of it, so you can browse your spaces and start new agents from your phone.

Why not a terminal app?

A terminal on a phone is not a good way to talk to an agent.

SSH apps give you a terminal wrapped for a wide screen: you pinch, scroll sideways and hunt for Esc and Tab. Shahi reads the saved conversations from Claude Code, Codex, Cursor CLI, Antigravity and OpenCode, so their messages fit your screen. Coverage depends on what each agent records: some tool results, images and other attachments may be unavailable. The original terminal is one tap away on the Screen tab, including for other agents herdr runs.

Connection security

How your connection is protected.

Your phone and computer lock the messages they send to each other using encryption. Shahi’s relay, a connection service on Cloudflare, passes those messages along without being able to read them.

What happens when I scan the code?
  1. The code lets your phone connect to your computer. It works once and expires after ten minutes.
  2. Your devices set up a protected connection. The relay cannot read the secret in your code.
  3. Your computer remembers the connected device so it can recognize it next time.
  4. Remove a device’s access in Settings to disconnect it and stop it from connecting again.

Keep your connection code private. Anyone who uses it can control the work running on your computer.

What information can Shahi see?

Shahi’s relay and its hosting provider, Cloudflare, can see connection information, such as your internet address, device identifiers, and when and how much data is sent. This helps diagnose connection problems and misuse. They cannot read the messages sent through this protected connection.

Your connected devices can read your messages, so keep them secure. The web app runs code from getshahi.dev, published by the same developer who runs the relay. A malicious release or a compromised website could read an open session or a remembered pairing, because encryption shields your messages from the relay, not from the app’s own code. The iPhone app comes through TestFlight and signed updates instead, and it can skip the relay by using your own SSH.

If you turn on iPhone notifications, Expo and Apple can read each one: the space name, the terminal title or pane name, the pane to open and your computer’s public identifier. Browser notifications are encrypted for your browser alone. Encryption cannot protect a device that someone has broken into or prevent connection outages.

Shahi’s security has been reviewed internally but has not had an independent audit. The security guide explains the encryption in detail.

Prefer no third party in the path? The iPhone app (beta) can connect over your own SSH instead. To stop your computer using the relay at all, add RELAY_URL= to the plugin’s .env and restart Shahi. QR pairing and the web app then stop working, and you connect over SSH.

Frequently asked questions.

What do I need before I connect?

Install herdr and your coding agent’s CLI on your Mac or Linux computer, then sign in to the agent or configure its provider credentials. Run your agents inside herdr and install the Shahi plugin. The setup section has the requirements and commands.

Will my agents keep working when I close Shahi?

Yes. Closing Shahi on your phone does not stop the agents running on your computer. Keep that computer or server awake and connected to the internet to receive live updates and send instructions.

Which agents can I read in Shahi?

Reader formats saved conversations from Claude Code, Codex, Cursor CLI, Antigravity and OpenCode. OpenCode and Antigravity need computer release 0.3.11 or newer, currently available on Beta: in Shahi’s Settings, select Beta, then Update computer. Coverage varies: some tool results, images and attachments are unavailable. Use Screen for the underlying terminal, including other agents herdr runs. See the Reader coverage and limits.

Is the Shahi tunnel free? Do I need a VPN?

Shahi’s built-in tunnel is ready to use and free for everyone. It uses outbound internet connections, so you need no Shahi account, VPN or port forwarding. Your agents still use their own provider accounts; any agent subscriptions or API charges are separate.

Can the relay read my conversations?

No. Conversation, file and command content is encrypted end to end between your device and computer. The relay and Cloudflare can see connection metadata, including IP addresses, identifiers, traffic size and timing. Read about connection security and its limits, including device security and optional notifications.

Can I connect more than one computer?

Yes. Pair each one from Settings → Computers → Add a computer. Tap the computer name on the main screen, or open Computers in Settings, to switch. Each computer keeps its own connection while Shahi is open.

Is there an iPhone or Android app?

The iPhone app is in a private TestFlight beta. Request an invite; invitations arrive by email as places become available. On Android, use the web app and add it to your home screen. The web app also works on iPhone; a native Android release is not currently available.
