Quick start

On the machine where herdr runs:

herdr plugin install iYassr/shahi
herdr plugin action invoke shahi.pair

That installs the sidecar as a user service, generates its secrets, and prints a QR code. Scan it in the app and your agents appear. There is no inbound port to open when using the relay.

How it connects

Your machine dials out and holds the connection open. Your phone dials out to the same relay. Neither side needs an inbound port, and the relay cannot read what it carries.

your machine herdr + sidecar
──▶ dials out, stays open
relay sees sizes and timing, never content
◀── sealed frames
your phone scan once

Every frame is sealed end to end between phone and sidecar, keyed from the pairing secret — which never travels. If you would rather have no third party in the path at all, the app can reach your box over an SSH tunnel instead.

The browser app trusts the code delivered by this website. A compromised website or publishing account could access an active session or remembered pairing secret. End-to-end encryption protects against the relay; it cannot protect against compromised app code. The relay can still observe connection metadata. Read the privacy policy for details.

What you can do

Read conversations

Shahi displays messages, reasoning, tool calls, and patches from Claude Code and Codex transcripts. Use Screen mode to view terminal output. Transcript entries that Shahi does not support are omitted from the reader.

Answer permission prompts

Review the request and choose an answer. Shahi checks that the prompt is still current before sending your response. If a prompt cannot be parsed, use the terminal view and text input.

Manage agents

Start agents in your workspaces, send messages, attach files, and use terminal keys from the app.

Connect to your computer

Agents run on your computer. Shahi connects to it through an encrypted relay, or through SSH in the mobile app. No Shahi account is required.

Availability

The iOS app is in private testing — there is no public App Store or TestFlight link yet. Open Shahi in your browser on a phone or laptop, then scan or paste a pairing code from the herdr plugin. Android is coming; iPhone is where this started.

The sidecar, the herdr plugin and the relay are working today. herdr is the supported backend; tmux is not supported.
