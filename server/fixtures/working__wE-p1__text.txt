     Risks

     - Undocumented behavior drift. The one-response-per-connection

     and fail loudly.

     not optimizations — measure the server process's CPU before and

     - Parser brittleness. Claude Code's prompt rendering will change.
     The design degrades gracefully to raw terminal + free text, so a
     parser miss is an inconvenience, not a breakage.
     - Digit-key answering is unproven. Verify before building the
     button UI on top of it.
