### OpenCode 2 conversations show in Read

OpenCode 2.2.0 keeps its conversations in a new place, so Read showed nothing for any conversation it ran. Shahi now reads them: your messages and the skills you picked, replies, thinking, tools and questions, and the notices OpenCode draws. Undo removes the undone messages from Read, as it does in OpenCode. Images attached in OpenCode 2 are named rather than shown for now. Computers still on OpenCode 1 read as before.

### Codex never shows another pane's conversation

When you start Codex yourself in several panes, Codex can report one pane's conversation as another's, and Read showed the wrong one. Shahi now checks that report against the conversation the pane's own title names, and shows nothing rather than the wrong conversation.

### Safer handling of phones and terminals

- A message or key press waiting behind another one is checked again when its turn comes, so it is never typed after its phone was signed out or removed, or into a pane that changed hands.
- The Changes view refuses to open a repository whose settings it could not read completely, rather than risk running a program the repository names.
- Web pages on other sites can no longer use up this computer's sign-in limit.
- When herdr is offline, Shahi says so in plain words instead of showing internal file paths.

### Web app

- Messages you send to Cursor no longer stay on screen twice.
- Arabic and Spanish fixes, and labels that were still in English.

### Compatibility

Supports herdr 0.9.0 and newer on protocol 22 (tested with 0.9.0 through 0.9.5), API 5 and encrypted transport 2. Checked against Claude Code 2.1.312, Codex 0.163.0 and 0.165.0, Cursor 2026.10.22, OpenCode 2.2.0 and Antigravity 1.4.8. Existing pairings and supported older apps remain compatible. No new app version is needed.
