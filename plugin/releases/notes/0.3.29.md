### Reader finds Codex started by hand inside a repository's subfolder

A Codex you start yourself is found by the conversation name in its terminal's title. Codex ends that title with the git repository's name, not the folder's, so a Codex started in a subfolder of a repository (say `project/server`) read "Nothing to read yet". Shahi now accepts either name. It still takes a conversation only when exactly one has that name in that exact folder.

Found by Shahi's new agent journeys (`bun run test:agents`), which start real Claude and Codex both from Shahi and by hand, and check that Reader and the agent list show each reply.

### Compatibility

Supports herdr 0.9.0 through 0.9.3, API 5 and encrypted transport 2. Existing pairings and supported older apps remain compatible. No new app version is needed.
