### Agent plan usage in Settings

Settings has a new Agents section showing how much of your Claude Code and Codex plans is used: the 5-hour and weekly windows, and when each resets.

Codex's limits appear automatically after its next turn. Claude Code reports its limits only to a status line, so they appear once you turn on **Show plan usage** under Claude Code. Shahi then adds a status line to Claude Code on that computer. If you already have a status line, it keeps working. Claude Code hides its footer hints, such as "esc to interrupt", while any status line is configured. Turning the switch off puts back the status line you had before.

Use iPhone TestFlight 1.0.0 (32) or later for the Agents section in the app; the browser app has it now.

### Compatibility

Supports herdr 0.9.0 through 0.9.3. Existing pairings, API 5 clients and encrypted transport 2 remain supported. Older apps show no Agents section; older computers do not offer it.
