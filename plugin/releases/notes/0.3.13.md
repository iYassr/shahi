### Open links in Reader

Reader recognizes plain HTTP and HTTPS URLs in messages, so an agent does not need to format a URL as a Markdown link before you can open it. Code stays literal, and existing links to files on your computer keep working.

### Compatibility

Existing pairings, conversations and API 5 clients continue to work. The matching iPhone change ships in a new TestFlight build, with long-press copying for individual web links.
