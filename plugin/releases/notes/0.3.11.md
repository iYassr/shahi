### OpenCode and Antigravity in Read mode

Read conversations, thinking, tool activity and recorded results from OpenCode and Antigravity on your phone. OpenCode also supports recorded image attachments, file links and undo boundaries. Live updates follow database changes as well as transcript files.

### Clearer Cursor conversations

Cursor now shows recorded failure and cancellation details and attachment labels. Rewritten transcripts clear outdated cached history. Tool output that Cursor omits from its export remains explicitly unavailable.

### More reliable session ownership

Claude, Codex and Cursor refuse ambiguous or out-of-root transcript files. Unknown providers cannot accidentally select a Claude conversation or image. Concurrent sessions in the same folder stay separate.

### Compatibility

Works with the existing Shahi iPhone app and browser clients. OpenCode requires its herdr integration; its empty home screen keeps the last reported conversation until the first prompt creates a new one. Antigravity inline images and formats not recorded by a provider remain available through Screen where applicable.
