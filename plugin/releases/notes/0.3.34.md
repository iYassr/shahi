### Cursor gets your first message after you trust a folder

When you answer Cursor's "Do you trust the contents of this directory?" and send a message straight away, Cursor spends about a second trusting the folder, and a message that arrived during that second was left typed but unsent, so Cursor never answered it. Shahi now waits for Cursor to finish before typing.

### Compatibility

Supports herdr 0.9.0 and newer on protocol 22 (tested with 0.9.0 through 0.9.5), API 5 and encrypted transport 2. Checked against Claude Code 2.1.304, Codex 0.163.0, Cursor 2026.10.19, OpenCode 1.19.3 and Antigravity 1.4.2. Existing pairings and supported older apps remain compatible. No new app version is needed.
