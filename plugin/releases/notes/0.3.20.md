### Fixes from testing a fresh install

A new Claude agent no longer opens on "This Claude conversation started before Shahi could identify it" while Claude is still asking whether to trust its folder. Claude Code 2.1.287 records nothing about the new conversation at that point, so the computer now reads the trust question on the screen instead, and offers no older conversations to choose from.

Notifications and lists call a new agent "Claude" or "Codex" until it names its conversation, instead of showing the command that started it. The folder picker leaves `node_modules` and the Mac's `Library` out of your home folder's list.

### Browser app

- An approval with a long diff keeps its answers on screen. The diff or command sits in its own box that scrolls, without the terminal's dashed rules or keyboard hints such as "(shift+tab)".
- An agent that is only showing its screen, not waiting on you, no longer gets the attention border.
- An offline computer is described once, with Switch computer and Retry connection in the same card.
- With no spaces yet, New agent starts at choosing the folder, then goes on to the agent. The agent you last started on this computer is chosen for you next time, and the chosen one is clearly marked.
- Agent and shell filters are labelled; Activity shows each step's time once per minute and file paths relative to the agent's folder; the setup commands stay one per line.

Use iPhone TestFlight 1.0.0 (33) or later for the same changes in the app.

### Compatibility

Supports herdr 0.9.0 through 0.9.3. Existing pairings, API 5 clients and encrypted transport 2 remain supported. Faster reconnection after a computer returns needs the updated relay and app 1.0.0 (33); older apps and computers keep their earlier behaviour.
