### More reliable agent approvals

Shahi recognises the current Codex, Cursor and Antigravity trust screens, Cursor command approvals and feedback, Antigravity edit and command approvals, and OpenCode's horizontal permission choices. Messages cannot accidentally approve these menus. Waiting cards remain visible when herdr has not yet recognised the question.

### Cursor appears in new conversations

Computers with the Cursor CLI now show Cursor in the agent picker even when the editor's separate launcher is absent.

### Codex Reader in every launch mode

New Full auto and Skip sandbox sessions keep their own session ownership, restoring Reader instead of silently attaching to a shared background server. Their sandbox and approval policies remain unchanged.

### Compatibility

This computer update works with the existing Shahi app. Antigravity and OpenCode still use Screen for their conversations; structured Reader support is not included.
