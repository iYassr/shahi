### The pairing code beside its QR

When the pairing window has room, the code now sits under the QR with what to do if the phone cannot scan it: in Shahi, tap **Paste pairing link**. On a Mac signed in to the same Apple Account as the iPhone, the code the computer copies reaches the phone's clipboard by itself. The QR keeps priority: in a small window it is shown whole on its own, and T then Enter still shows the code as text.

iPhone TestFlight 1.0.0 (34) or later adds **Can't scan? Paste pairing link** to the camera screen, so a code the camera cannot read can be pasted from there.

### Compatibility

Supports herdr 0.9.0 through 0.9.3. Existing pairings, API 5 clients and encrypted transport 2 remain supported.
