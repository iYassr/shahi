### Reader keeps finding Codex conversations on a Mac

0.3.27 found a Codex conversation you started yourself by the name in its terminal's title. On a Mac that lookup worked only while Codex had its conversation index open: Codex removes the index's companion files when it closes it, and macOS's SQLite then refused to read it. Between uses, the conversation's row read "No messages yet". Shahi now reads the index in that state too, without writing anything into Codex's folder. Linux computers were not affected. OpenCode conversations get the same fix.

### Compatibility

Supports herdr 0.9.0 through 0.9.3, API 5 and encrypted transport 2. Existing pairings and supported older apps remain compatible. No new app version is needed.
