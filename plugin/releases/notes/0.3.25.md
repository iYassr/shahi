### English, Arabic and Spanish

The browser app follows your device language or a saved choice in Settings: English, العربية or Español. Menus, onboarding, settings and common messages are translated, with Arabic layout support. Switching language keeps your connection and reply draft. Agent conversations, code, computer names and terminal output keep their original text.

The matching iPhone update brings the same language choices and is distributed separately through the App Store.

Renamed files in Changes have a complete, natural screen-reader announcement.

### Notifications and agent compatibility

The browser app can reopen a conversation from a notification while its shell is offline. Latest Codex startup notices remain answerable without guessing a menu choice. Validated against herdr 0.9.3, Codex 0.160.0 and Claude Code 2.1.289; existing startup screens stay supported.

### Compatibility

Supports herdr 0.9.0 through 0.9.3, API 5 and encrypted transport 2. Existing pairings and older supported apps remain compatible. Language selection changes the interface, not the agent's language or the English live dictation model.
