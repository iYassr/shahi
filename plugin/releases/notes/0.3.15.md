### Recover missing Reader conversations

New Codex conversations can be read without installing agent integrations. When a Claude conversation cannot be identified automatically, choose it explicitly. Reader stays open while a new transcript becomes available and never guesses from another conversation in the same folder. Existing Codex sessions using the old shared daemon may need to be reopened through the updated launcher.

### Answer startup questions from your phone

Codex startup update and folder-trust questions appear as answerable cards, including while herdr still reports the agent idle. New conversations no longer silently wait behind those menus.

### Private diagnostics and update recovery

Optional diagnostics report Reader failures without conversation text, file paths or raw error messages. An expiring update requirement can direct supported clients to a necessary frontend update; it is disabled by default.

### Compatibility

Supports herdr 0.9.0 through 0.9.3. Existing pairings, API 5 clients and encrypted transport 2 remain supported. Use iPhone TestFlight 1.0.0 (27) for the matching Reader recovery controls and dictation fixes.
