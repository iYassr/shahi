### Safer conversations and recovery

Drafts and retries belong to the computer and conversation they were written for. Reused panes, repeated questions, interrupted uploads and uncertain sends now retain or discard their state at the correct boundary. The app explains interrupted connections and keeps unavailable actions disabled until recovery.

### Multiple computers

Saved computers can have personal names, including clear distinctions between duplicate hostnames. Waiting work on other computers stays visible, available computers can be opened directly, and cancelling an added computer returns to the previous selection.

### Reader and controls

The native reader keeps loaded history across gaps in incoming updates. Free-text question options open the reply field, sending brings the latest message into view, prompts leave room for the keyboard, and filenames and message controls are easier to read. Native changes require an updated iPhone build.

### Service and security fixes

This release includes the September prerelease review fixes for request ownership, idempotent writes, bounded transcript and file transfers, reconnects, pairing, push registration, plugin startup and managed recovery. API 5 and encrypted transport 2 remain compatible with supported clients. Dependency versions are unchanged.

### Validation and limits

See `docs/review-completion-2026-09-26.md` for the validation record and outstanding infrastructure and physical-device checks. Plain HTTP redirects and the minimum TLS version still need their Cloudflare zone settings confirmed. Input already queued in a terminal before another program starts cannot be recalled by Shahi.
