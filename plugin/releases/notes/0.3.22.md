### Crash reports that say what went wrong

With **Share diagnostics** on, a report now keeps the error's type and message, and for iPhone crashes the reason (signal, exception code), instead of "message omitted for privacy". Before it leaves the device, the message has its links, email addresses, file paths, long numbers, long identifiers and quoted text replaced by placeholders such as `<path>` and `<text>`. Conversation text, screenshots and network requests are still never sent. The privacy policy and the Settings description say exactly this.

This release covers the browser app; iPhone TestFlight 1.0.0 (35) or later applies the same rules to native crashes.

### Compatibility

Supports herdr 0.9.0 through 0.9.3. Existing pairings, API 5 clients and encrypted transport 2 remain supported.
