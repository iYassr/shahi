### A quieter Reader

Routine commands, file reads, tool calls and thinking now share one expandable Activity section beneath each agent turn. Written responses remain visible with one Agent heading and timestamp. Files, images, questions and failed steps remain accessible without opening routine activity.

### Follow work without the noise

While the agent works, Activity shows one current status and a step count. It collapses when the work finishes and can be reopened to inspect the original commands, timestamps and outputs. The same presentation applies to all five supported Readers.

### Compatibility

Supports herdr 0.9.0 through 0.9.3. Existing pairings and API 5 clients continue to work. The matching iPhone Reader change ships in a new TestFlight build.

### Reader recovery

New Codex conversations can be read without installing agent hooks. When a Claude conversation cannot be identified automatically, choose it explicitly. Reader stays open while a new transcript becomes available and never guesses from another conversation in the same folder.

Codex's startup update and folder-trust questions appear as answerable cards, including when herdr still reports the agent idle. A new conversation no longer silently waits behind those menus.

### Private diagnostics and update recovery

Optional diagnostics report Reader failures without conversation text, file paths or raw error messages. A separately served, expiring update requirement lets Shahi direct supported clients to a necessary frontend update; it is disabled by default.
