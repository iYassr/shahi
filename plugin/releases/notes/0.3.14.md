### A quieter Reader

Routine commands, file reads, tool calls and thinking now share one expandable Activity section beneath each agent turn. Written responses remain visible with one Agent heading and timestamp. Files, images, questions and failed steps remain accessible without opening routine activity.

### Follow work without the noise

While the agent works, Activity shows one current status and a step count. It collapses when the work finishes and can be reopened to inspect the original commands, timestamps and outputs. The same presentation applies to all five supported Readers.

### Compatibility

Existing pairings and API 5 clients continue to work. The matching iPhone Reader change ships in a new TestFlight build.
