### Claude's background subagents show as running until they finish

Claude Code 2.1.311 changed how a subagent running in the background reports back. A subagent that paused to wait on work of its own was shown as done within seconds, while Claude still showed it running, and when it really finished, its report arrived in a form Shahi did not read. Shahi now shows it running until it really ends, then done with its report, as Claude's own panel does.

### Compatibility

Supports herdr 0.9.0 and newer on protocol 22 (tested with 0.9.0 through 0.9.5), API 5 and encrypted transport 2. Checked against Claude Code 2.1.312, Codex 0.165.0, Cursor 2026.10.22 and Antigravity 1.4.8. Existing pairings and supported older apps remain compatible. No new app version is needed.
