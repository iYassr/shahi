The computer service and herdr plugin with the fixes from the pre-release review. Update from the app's Settings, or run `herdr plugin install iYassr/shahi` again, which also brings the new plugin actions. Paired phones and browsers keep their pairing.

### Connections and security

- Files, PDFs, and Save/Share now work through the relay. Ranged downloads were missing two response headers and failed with "The computer returned an incomplete file."
- A phone that was revoked while offline is signed out the next time it connects. A session that only expired reconnects instead of being unpaired.
- Several large replies in a row wait for the relay's acknowledgments instead of ending the link.
- The computer now tells the relay which phones have proved they hold their secret. Someone who knows a device id but not its secret can no longer keep your phones out. This needs the relay deployed on 25 September 2026.
- The local listener only answers `Host` values of `127.0.0.1`, `localhost`, or `[::1]`, which protects against DNS rebinding. List your own reverse proxy in `SHAHI_ALLOWED_HOSTS`.
- Sign-ins and pairing claims now have their own small admission budget. A flood of wrong passcodes can no longer make phones see "busy".
- Uploads:
  - Starting an upload replaces your own unfinished one.
  - Idle transfers are cleaned up after 10 minutes.
  - Uploaded files are written with private permissions (0600).
  - Access is checked again after the body arrives.

### Agents and conversations

- Codex 0.151 and later show reasoning, MCP calls, file edits, and web searches again.
- A new Codex or Cursor session in the same pane no longer shows the previous session's messages. The reader follows `/clear` and new sessions.
- Claude Code's compaction summaries and `!cmd` rows no longer appear as your own words. Cursor shows only what you typed.
- A typed message is refused while a menu is open on the agent's screen. Pressing Enter on a permission menu used to approve the highlighted command.
- Answer buttons appear once herdr catches up with a menu that is already on screen. An answer is only pressed if the question and its context still match.
- Prompts and agent starts that never reached herdr can be retried safely.
- Sessions with more than 64 agent panes no longer re-read every transcript every 3 seconds.

### Plugin and install

- The pair popup stays open until you press Enter, so the first-run passcode and any failure stay readable.
- New `reset-passcode` action.
- Supports herdr 0.9.0 and 0.9.1. A computer that can't run a release is told which versions it needs.
- Alpine, which has no systemd, gets a working command to hand to its own init system.
- The service removes itself once herdr no longer has the plugin.
- `/api/meta` and `shahi.status` report the real version. 0.3.6 reported 0.3.4.

### Compatibility

API 5 and encrypted transport 2. This release works with current apps and the previous generation. TestFlight build 16 and the web app at getshahi.dev/pwa carry the matching client fixes.
