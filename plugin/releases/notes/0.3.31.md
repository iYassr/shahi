### Shahi keeps running through changes to herdr's plugin list

Shahi removes its own service when you uninstall or disable the plugin in herdr, and it found out by asking herdr's plugin list. A later herdr that lists plugins differently, or a list read while it was being rewritten, could have looked like an uninstall and removed Shahi. Shahi now counts the plugin as uninstalled only when herdr has also deleted its files, which a real uninstall does. Disabling the plugin still stops Shahi, as before.

### Beta computers get Stable releases too

A computer on the Beta channel looked only at Beta releases, so a fix published straight to Stable, like 0.3.30's, never reached it. Beta computers now choose the newest release from both.

### Compatibility

Supports herdr 0.9.0 and newer on protocol 22 (tested with 0.9.0 through 0.9.5), API 5 and encrypted transport 2. Existing pairings and supported older apps remain compatible. No new app version is needed.
