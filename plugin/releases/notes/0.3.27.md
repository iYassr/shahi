### Reader finds Codex conversations you started yourself

Codex 0.160 runs a conversation started with a plain `codex` inside a shared background process, so it reported no session to herdr and held no conversation file open in its own terminal: Reader said "Nothing to read yet" for every Codex you started by hand. Shahi now reads the conversation's name from the title Codex gives the terminal and opens the one conversation with that name in that folder. A conversation without a name yet, or a name two conversations share in one folder, is still not guessed.

### One line to set up a computer

`curl -fsSL https://getshahi.dev/install | sh` installs herdr if it is missing (checked against its published SHA-256 first), then Shahi, starts herdr in the background and shows the pairing code. The browser app, the website and the README now lead with it; the herdr plugin commands remain for anyone who already runs herdr. The pairing code printed in a terminal now appears under its QR, with what to do if the camera cannot read it.

Use iPhone TestFlight 1.1.0 (41) or later for the same welcome screen in the app.

### Compatibility

Supports herdr 0.9.0 through 0.9.3, API 5 and encrypted transport 2. Existing pairings and supported older apps remain compatible.
