### Answer every startup screen from your phone

Menus an agent shows before or outside its conversation now arrive as answerable cards even while herdr reports the agent idle: Codex's sign-in, update, folder trust, hooks review and model change, and Claude Code's theme, sign-in, folder trust, bypass warning, project MCP servers, API key, external imports and settings errors. A card shows the dialog's title, and an answer presses Enter only after the cursor has reached the chosen row.

### Nothing is typed into a screen Shahi cannot read

When an agent waits on something no parser recognises, a message is refused instead of typed, because letters can move a menu's cursor and Enter would pick its highlighted row. The phone shows the screen itself with keys instead, and does the same for a new agent until its conversation begins. An agent that exits while starting, such as an outdated Claude Code, is quoted in the error.

### Compatibility

Supports herdr 0.9.0 through 0.9.3. Existing pairings, API 5 clients and encrypted transport 2 remain supported; older apps show the refusal as text and keep the Screen keys. Use iPhone TestFlight 1.0.0 (28) for the screen card.
