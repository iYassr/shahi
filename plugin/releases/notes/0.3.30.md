### Works with herdr 0.9.4, 0.9.5 and later herdr releases

herdr 0.9.4 and 0.9.5 speak the same protocol as 0.9.3, but Shahi accepted only the herdr versions it had been released with. Every computer that updated herdr showed "This herdr release needs a tested Shahi adapter" and refused its agents. Shahi now goes by herdr's protocol, which is herdr's own promise about its API, instead of its version number. A herdr release on the same protocol simply works. A newer protocol is tried too, and Shahi asks for its own update only if it really cannot read that herdr. Updates are chosen the same way, so a herdr update no longer leaves a computer with no Shahi release to install.

If your phone shows "Update required" after updating herdr, tap Check for updates once to install this release.

### Images in conversations Claude moved

When Claude Code continues a conversation in a new file, or parks it as a background job, Reader follows it, but its images were still looked for in the old file and showed "This image could not be loaded". Images now come from the same file Reader shows.

### Also in this release

- Codex 0.162.1's "model no longer available" notice is recognised, so a message is not sent behind it.
- The browser app says how to start herdr when it is not running, no longer calls a live connection offline, and its Check again finds agents installed after pairing.

### Compatibility

Supports herdr 0.9.0 and newer on protocol 22 (tested with 0.9.0 through 0.9.5), API 5 and encrypted transport 2. Existing pairings and supported older apps remain compatible. No new app version is needed.
