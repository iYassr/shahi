### New conversations appear first

New Claude and Codex sessions now have a start time before their first message.
Updated clients place them above older conversations, with pinned conversations
first. Reconnecting or a status change does not move a conversation up the list.

### Clearer permission choices

Claude and Codex start with explicit Ask me settings when a client omits its
selection. Codex modes that ask the user no longer inherit automatic review.
Invalid selections fail before creating an empty tab.

### More complete Reader conversations

Reader supports current Codex questions, plans, command output, reviews, tool
failures and extension activity. Inline images use the authenticated image viewer;
local image links open in the file viewer. Claude plain-text replies retain the
correct speaker. Reused panes immediately refresh their transcript location.

### Compatibility

The computer changes work with API 5 clients. The new-session ordering also
requires the updated phone or browser client. Inline audio playback remains
unavailable. Existing herdr sessions and saved pairings are preserved.
