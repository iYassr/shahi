### Changes

Each agent has a third view beside Read and Screen: **Changes**, what it has changed in its folder's Git repository since the last commit. Files are listed with their status and added and removed lines; tap one for its diff. It only reads: nothing is committed, staged or discarded, and the computer runs Git with every program a repository's own settings could start switched off.

### Answer from the notification

When an agent asks before running a command or editing a file, the iPhone notification can now show what it is asking, with the answers as buttons: long-press the notification, choose an answer, and unlock if asked. The computer checks the answer against the screen as it is at that moment, exactly as when you tap a card, and presses nothing if the question has changed.

What the agent asks is encrypted on the computer with a key only the phone that made it holds, and opened on the phone; Expo and Apple carry only that encrypted content. It needs a phone paired through the relay with iPhone TestFlight 1.0.0 (36) or later. Turn notifications off and on again in Settings once to start. Computers reached over SSH or signed in with the passcode keep the notifications they had. The browser app's notifications now include the question too.

### Slash commands and quick replies

Type `/` in the reply box for the agent's commands, including your own Claude Code commands and skills, or tap **/**. When an agent is waiting for your next message, chips such as **Continue** and **Yes, go ahead** send a reply in one tap; they never replace something you have typed.

### Fixes

- A Mac is named by the Computer Name in System Settings, not the network-assigned hostname, which showed as a string like `FA-F5-F2-84-C0-7E`.

### Compatibility

Supports herdr 0.9.0 through 0.9.3. Existing pairings, API 5 clients and encrypted transport 2 remain supported. Changes, encrypted notification content and the command list are offered as new capabilities: older apps do not show them, and newer apps do not show them for older computers.
