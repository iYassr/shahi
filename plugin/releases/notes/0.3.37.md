### Newest Claude Code, Codex and Cursor

- Cursor CLI 2026.11: Read finds its conversations again, and a message sent while Cursor is still trusting the folder tells you to send it again in a moment instead of asking for keys on a screen with nothing to answer.
- Claude Code 2.1.323: a PDF sent with a message now says it was attached, where Read showed the words alone.
- Claude Code and Codex startup screens reworded in November (sign-in, folder trust) are still answered from the phone.
- A Claude Code pane that runs with its own `CLAUDE_CONFIG_DIR`, such as a second account, now shows its conversation in Read.

### Answers and new agents

- An answer is never pressed twice when the computer could not tell whether the first one landed.
- An agent that takes a long time to start opens on its screen instead of reporting that it is still starting for minutes after it came up.
- A Claude conversation you chose for a pane is released once that Claude quits, so another pane can show it.

### Updates and recovery

- A failed update is remembered and reported, not lost when the computer or the manager restarts, and is not retried on its own every time herdr starts.
- Logging out or restarting during an update no longer marks a good release as failed.
- The update card no longer sticks on "Requesting update".

### Phones and connections

- A phone's notifications keep working when it switches computer while registering.
- An upload left between its check and its result finishes instead of vanishing.
- A link that hangs during its first hello no longer shows LIVE indefinitely.

### Compatibility

Supports herdr 0.9.0 and newer on protocol 22 (tested with 0.9.0 through 0.9.5), API 5 and encrypted transport 2. Checked against Claude Code 2.1.325, Codex 0.167.2 and 0.169.0, Cursor 2026.10.22 and 2026.11.11, OpenCode 1.19.5 and 2.2.0, and Antigravity 1.5.8. Existing pairings and supported older apps remain compatible. iPhone app 1.1.5 carries the phone-side fixes.
