### Reader shows what Claude Code keeps on screen

Two kinds of lines Claude Code leaves in a conversation were missing from Reader. Each run of a `/loop` or scheduled task now shows "Running scheduled task (…)" above it, as the terminal does, and a warning Claude Code shows in the conversation, such as a monitor that did not resume, appears as a note. A model switch you agreed to is explained the way a switch after a refusal already was. Claude Code 2.1.301's new log of each request, written into the same file, is ignored, so no reply appears twice.

### Codex's model notice on Linux

When Codex says a model is no longer available, it waits for Enter or Esc. On Linux it labels its quit key differently from macOS, so Shahi did not recognise that screen and offered a message box, whose Enter would have accepted the change unread. The phone now shows the screen with keys on Linux too.

### herdr found where its installer puts it

A computer whose service did not know herdr's location looked only on its own PATH, so it could not tell whether the plugin was still installed. It now also looks in `~/.local/bin`, `/opt/homebrew/bin` and `/usr/local/bin`.

### Compatibility

Supports herdr 0.9.0 and newer on protocol 22 (tested with 0.9.0 through 0.9.5), API 5 and encrypted transport 2. Checked against Claude Code 2.1.304, Codex 0.163.0, OpenCode 1.19.3 and Antigravity 1.4.2. Existing pairings and supported older apps remain compatible. No new app version is needed.
