### Codex questions in Reader

Codex 0.160.0's structured questions, choices and explanations stay visible in Reader. Completed async questions appear once, and replies remain readable when Codex records a single answer object or adds IDE context.

### Choosing an answer

Codex's Add notes button opens its real notes field, where you can send a single-line note from Reader. If the question or selection changes while typing, Shahi leaves the text there and withholds Enter.

After selecting an editable answer field in the browser, you can still choose a predefined answer instead. The matching iPhone update also keeps answered or closed question buttons from returning through an older frame and preserves the agent's original wording in every interface language. The iPhone update is distributed separately through the App Store.

### Compatibility

Supports herdr 0.9.0 through 0.9.3, API 5 and encrypted transport 2. Existing pairings and supported older apps remain compatible.
