# Welcome to the Shahi review computer

This is an isolated sample project. It contains no personal files.

Try opening `index.html`, creating an agent, asking it to improve the page, and
sending a small attachment. You can also create a shell and run `ls` or
`cat README.md`. Nothing here changes the developer's own computer.

Use sample information only. This review environment and its recovery snapshots
are hosted by Cloudflare. The Codex client uses a local scripted responder, not a live AI model.
Try "list files", "read the README", or "create a sample file". No prompts are
sent to an AI provider. Contact support@getshahi.dev for assistance.
